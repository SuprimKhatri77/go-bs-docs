Everything below runs the published bikram-sambat-react package. Pick the calendar or the date
picker, change its props, and adjust the colors and sizes of the default stylesheet. The code
underneath always reproduces what you see: the component with the props you changed, and a CSS
rule with just the variables you edited.

A few things the playground doesn't cover, because they need your own code:
[`classNames`](/docs/react/guides/styling#classnames) and [`unstyled`](/docs/react/guides/styling#unstyled)
for styling with your own classes or Tailwind, [`components`](/docs/react/guides/styling#replacing-parts)
for replacing parts, and [`renderDay`](/docs/react/api/calendar#custom-day-content) for custom day
content.
